# Data Directory

This directory is **gitignored** — its contents are machine-specific and not tracked in version control.

## What lives here

On the development machine, this directory contains:

- `dataset.npz` — BiLSTM rep counter training data (5-class depth labels, ~10k samples)
- `dataset_5class.npz` — Alternate 5-class dataset variant
- `test_dataset.npz` — Held-out test split for BiLSTM evaluation
- `test_v2.npz` — V2 test data with updated label scheme
- `debug_trajectory.png` — Debug visualization of a squat trajectory
- `squats.mov` — Reference squat video for pipeline testing
- `squats.html` — HTML visualization of squat analysis

## How to get this data

If you need these files for training or testing, ask the project owner. The datasets are generated by `scripts/tools/generate_opensim_data.py` (synthetic) or captured from real squat sessions.
